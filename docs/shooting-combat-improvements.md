# 슈팅 전투 개선 — 2026-10-30

기존 방 만들기·대기실·재도전·사용권 개선은 유지하고 전투 성장, 몬스터, 시각 효과를 변경했다.

## 성장과 총 고정

- 레벨당 기본 공격력의 6%, 최대 체력 12, 방어력 4가 자동 증가한다. 살아 있는 플레이어의 현재 체력도 증가분만큼 회복한다. 쓰러진 팀원은 최대 체력·방어력만 성장하며 자동 부활하지 않는다.
- Q/E 스킬과 집중 사격·방어 태세·충격파, 장착 선택을 서버·공유 타입·네트워크·입력·HUD에서 제거했다. 대시와 무적·부활 소모 아이템은 유지한다.
- 선택한 총은 도전 내내 고정한다. 보스 뒤 무기 교체 정비 단계를 제거했다. 결과 화면에서 모두 다시하기에 동의하면 새 도전의 대기실에서 총을 다시 선택할 수 있다. 구형 클라이언트의 `refit`·`equip`·`skill` 요청으로 변경할 수 없다.
- 레벨업에는 현재 총의 강화 세 개만 제공한다. 화면의 이전→다음 수치와 서버 탄환 판정은 공유 패키지의 동일한 계산을 사용한다. 제한에 도달한 카드는 비활성화하고 시간 초과 자동 선택에서도 제외한다.

크기·집탄·범위 외의 투자는 누적할 수 있다. 극단적으로 많은 산탄은 최대 21개의 대표 탄환에 피해를 합산하고 과도한 연사도 기존 방식으로 피해를 합산해 생성 비용을 제한한다.

유탄의 기본 직격 피해는 42, 기본 폭발 피해는 33.6이며 자동 공격력 성장을 함께 적용한다. 명중 대상은 직격과 폭발을 각 한 번 받고 주변 적은 폭발만 받는다. 고폭은 폭발 피해만, 광역은 반경만 강화한다. 첫 광역 강화부터 반경이 88→96.8로 증가한다. 벽 충돌 때 두 경로에서 폭발하던 중복 효과·이중 피해를 제거했다.

같은 스테이지·인원에서 근접 4종의 체력은 원거리 3종보다 모두 높다. 1스테이지는 추격·돌진·사수, 2스테이지부터 전체 일반 종류가 등장한다. 원거리 공격은 계속 한 번에 탄환 하나 또는 포격 지점 하나다.

원거리 적이 엄폐물 뒤에서도 사거리만 보고 멈추던 문제를 수정했다. 벽에 가렸으면 시야를 확보할 때까지 우회한다. 길찾기는 몬스터 반경별 공유 흐름장을 사용하고 실제 크기로 경로 선분까지 검사해 모서리 끼임을 방지한다. 벽에 막힌 후퇴·옆걸음은 추격 경로로 전환한다. 시야와 적정 사거리를 확보한 사수·포격병은 잠시 서서 공격하는 것이 정상이다.

## 의미별 효과

- 처치: A안의 작은 장갑·금속 파편이 회전하며 퍼지고 가라앉아 사라진다. 보스는 파편 수가 더 많다.
- 폭발: 짧은 각진 섬광→불꽃 조각→잔연기. 오래 남는 노란 원을 제거했다.
- 적 공격: 사격 조준선, 돌진 통로·화살표, 근접 휘두르기 호, 포격 위험 지점·낙하 화살표를 구분한다. 포격은 원형 피해 판정과 일치하는 짧은 점선 경계와 내부 위험 선을 유지한다.
- 회복: 상승하는 초록 십자. 부활: 빛기둥과 상승 화살표. 무적: 육각 장갑.
- 클리어: 전장 스캔과 양쪽 청록 리본, 기존 클리어 배너. 수거 시간은 추가하지 않는다.
- 충격파는 스킬 삭제와 함께 제거했다. 바닥의 큰 장식 원·캐릭터의 상시 외곽 원도 정리했다.

효과는 서버의 수명·ID로 진행률과 파편 궤적을 계산한다. 효과마다 타이머·게임 오브젝트를 추가하지 않고 기존 Graphics를 재사용한다. 실제 피해 판정은 시각 효과 개수 제한과 독립적이다.

## 검증과 한계

- 격리 시뮬레이션 **20개 통과**: 12개 강화, 성장·죽은 팀원, 최대 강화·시간 초과, 총 고정, 보스 후 진행, 유탄 벽·직격 피해, 관통·대구경 실제 충돌, 산탄 생성 제한, 근접/원거리 체력, 16~54 반경 장애물 우회, 벽 뒤 사수, 단일 원거리 공격, 경험치·아이템 폐기, 네트워크 필드, 방장 승계를 확인했다.
- 실제 `ShootingRoom`·Colyseus·프론트 SDK 두 소켓의 격리 연결 검증 **6개 통과**: 서로 다른 총, 자동 성장, 전용 강화와 재개, 새 효과 직렬화, 재도전 후 총 재선택, 퇴장 후 두 사용권 반환을 확인했다. 인증·기록 백엔드는 검증 전용 HTTP 저장소를 사용했다. 실제 계정·기록은 생성하지 않았다.

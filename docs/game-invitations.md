# 공통 게임 초대와 슈팅 대기실

적용일: 2026-10-29

## 화면과 처리 흐름

- 오목·같은 그림 찾기·슈팅의 친구 선택, 15초 카운트다운, 취소·수락·거절, 로그인 변경 방지와 방 이동을 `src/features/game-invitations`에서 공유한다. 기존 두 게임의 팝업 디자인은 유지한다.
- `SocialOverlayHost`가 게임별 팝업 여러 벌 대신 `GameInvitationHost` 한 벌을 표시한다. 홈·게임·별도 게임 창·전체 화면에 같은 수신 큐를 사용하고, 네이티브 모달이 열렸으면 그 안에서 표시해 버튼이 비활성화되지 않게 한다.
- 동시에 온 초대는 만료가 빠른 순서로 하나씩 표시한다. 만료된 카드는 즉시 숨기고 한 번 재확인하며 유효한 초대가 없으면 표시 타이머도 중지한다.
- 게임 이름·아이콘·설명·규칙·허용한 입장 경로만 게임 등록 정보에서 바꾼다. 서버가 임의 이동 URL을 전달하지 않는다.
- 기존 오목·같은 그림 찾기는 각 서버의 방장 문서·비공개방·좌석·참가 권한 검증을 그대로 사용한다. 공통 UI가 이 검증을 우회하지 않는다.

## 신규 게임 연결

1. `contracts.ts`에 공개 초대·방 번호 검증과 게임 식별자를 등록한다.
2. `registry.ts`에 표시 정보, 전송·응답 어댑터와 고정된 입장 경로를 연결한다.
3. 전용 초대창을 복사하지 않고 `GameInviteDialog`에 게임·방·세션을 전달한다. 기존 게임의 페이지 소유권이 필요하면 `pageId`도 전달한다.
4. 신규 서버 구현은 `domain/gameinvite/GameInvitationAdapter`로 방장 권한·현재 방 버전·수신자 참가 가능 여부만 연결한다. 공통 서비스가 기한·중복 요청·본인 응답·상태 저장·소셜 변경 방송을 처리한다.

`components/ui/game-dialog.tsx`는 게임에 종속되지 않는 네이티브 모달이다. 기존 오목의 `RoomDialog` 사용 경로는 래퍼로 유지하며 기존 스타일도 전달한다. 공개 프로필 계약은 `social/person-contracts.ts`에서 공유해 소셜·초대의 순환 의존을 방지한다.

## 슈팅 상세 화면

- 조작 안내 오른쪽의 **랭킹** 버튼으로 1인·2인 TOP 100을 연다. 화면 하단 랭킹과 게임 목록 버튼은 제거했다. 랭킹은 창을 열 때만 조회한다.
- 2인 모드에 방 목록·검색·친구 필터·새로고침·번호 페이지 이동을 제공한다. 한 페이지 4개를 표시해 FHD에서 주요 동작에 접근할 수 있게 한다. 작은 화면은 글자를 과도하게 줄이지 않고 단일 열과 세로 스크롤을 사용한다.
- 대기 중이고 방장만 접속한 방을 표시한다. 목록은 보이는 동안 5초 간격으로 갱신하고 숨은 탭·전투에서는 중지한다. 친구·차단은 일괄 SQL, 사용권은 Redis 일괄 조회로 확인한다.
- 대기실에서 친구 초대·초대 링크 복사·방 코드 복사·무기 선택을 제공한다. 초대 수락과 링크 참가는 기존 인증·참가권·브라우저 증명·정원 검증을 통과한다. 두 사람 모두 준비하면 전투로 전환한다.
- 전투 시작·만석·연결 끊김·방장 퇴장은 목록에서 제외한다. 전투 전 방장이 퇴장하면 대기실을 닫고 다른 참가자를 목록으로 돌려보낸다. 전투가 시작된 뒤의 퇴장 규칙은 기존대로 남은 사람이 계속 진행한다.
- 게임 서버는 HMAC 내부 API로 25초 대기실 임대를 갱신한다. 서버가 사라진 방을 영구적인 공개 목록에 남기지 않는다.

## 적용과 검증

백엔드를 재시작하면 Flyway V34가 `tbl_game_invitation`을 추가한다. 게임 서버도 재시작하고 프론트에 변경 소스를 반영한다. 채팅 서버는 기존 본인 전용 `SOCIAL_CHANGED` 변경 알림을 사용하므로 코드 변경이 없다.

브라우저 검증은 합성 계정·프론트 API 응답과 HMAC을 검증하는 임시 인증 서비스, 실제 Colyseus 서버·빌드한 Next.js 화면을 사용했다. 실제 계정의 전체 Spring 인증 및 채팅 서비스까지 함께 실행한 통합 검증과 실제 macOS Safari·iPhone·iPad 검증은 이번 검증 범위에 포함하지 않았다.

상세 측정과 화면은 루트 `.codex-artifacts/shooting-invitations-20261029`에 보관한다. 임시 테스트 소스는 검증 후 삭제한다.

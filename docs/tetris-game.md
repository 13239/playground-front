# 테트리스 1인 플레이

## 진입과 화면

- `/games/tetris`는 기존 사이트 헤더·로그인 세션·게임 카탈로그를 재사용한다. `TETRIS / SINGLE`만 등록하며 방·채팅·다인 플레이를 만들지 않는다.
- 기준 시안은 `docs/design/tetris/desktop-lightline-v1.png`이다. 밝은 페이지, 상단 개인 통계, 어두운 LIGHTLINE 블록, 홀드·다음 블록, TOP 100을 구현한다.
- 사용자 수정 요청대로 랭킹 아래의 **내 기록 카드**와 **순위 범위/전체 인원 문구**는 제공하지 않는다. 상단의 최고 점수·내 순위·플레이 횟수는 실제 DB 값이다.
- 게임판은 표준 10×20칸이며 숨김 행 2개를 별도로 계산한다. 작은 화면은 랭킹을 게임 아래로 배치하고 주요 동작과 터치 조작을 판 아래에 둔다.
- Phaser 4.2.1은 인증·게임 이용 확인 뒤 해당 게임에서만 지연 로딩한다. 페이지 이탈·계정 변경 시 엔진, 이벤트, 오디오, 미제출 입력을 정리한다.

## 규칙 v1

- 60Hz 정수 tick을 사용하는 규칙은 Phaser·React와 분리한다. 서버의 `TetrisReplay`도 같은 시드·명령·tick 순서로 재생한다.
- 7-bag 블록 공급, 다음 블록 5개, 블록당 한 번의 홀드, 고스트, SRS 회전 보정을 지원한다.
- 좌우 이동은 처음 150ms 후 약 33ms마다 반복한다. 소프트드롭도 약 33ms 간격이다. OS 키 반복 속도와 화면 FPS에 의존하지 않는다.
- 착지 후 500ms에 고정하고, 착지 상태에서 이동·회전으로 고정 시간을 최대 15번 갱신한다.
- 줄 제거 점수는 1/2/3/4줄에 100/300/500/800 × 현재 레벨이다. 소프트드롭은 칸당 1점, 하드드롭은 칸당 2점이다. T-spin·콤보·백투백 가산점은 이 버전에 없다.
- 10줄마다 레벨이 오르고 중력 간격은 `max(3, 48 - (레벨 - 1) × 4)` tick이다.
- 방향키: 이동·시계 회전·소프트드롭. Space: 하드드롭. C/Shift: 홀드. P/Escape: 일시정지. X/Z: 시계/반시계 회전.
- 창 포커스 상실·탭 숨김·설정 열기는 자동 일시정지하며 자동 재개하지 않는다. 설정을 열기 직전 플레이 중이었다면 설정을 닫을 때 재개한다.
- 게임오버·명시적 다시 시작 시 해당 판을 저장한다. 새로고침·페이지 이탈 시 진행 중인 판의 복원/저장은 제공하지 않는다.

## 저장과 보안

- Flyway V22는 카탈로그의 기존 순서 뒤에 테트리스를 추가하고 `tbl_tetris_run`, `tbl_tetris_player_stats`를 만든다. MVC 서버 재시작 시 적용한다.
- 시작 API는 공통 게임 공개/점검 정책을 다시 확인한다. 계정별로 진행 정보 한 건만 두고 로그인 세션과 플레이 UUID를 결합한다. 다른 탭에서 새 판을 시작하면 이전 판의 제출은 거절된다.
- `POST /api/tetris/overview`, `/start`, `/finish`는 기존 BFF·쿠키·JWT·Origin·브라우저 서명·계정 변경 경계를 공유한다. 신규 인증 쿠키나 공개 기록 변경 경로를 만들지 않는다.
- 시작 UUID 재요청은 같은 시드를 반환한다. 플레이 횟수는 성공한 새 판 시작에서 한 번만 증가한다.
- 종료 요청에는 점수를 받지 않는다. 서버가 시드와 `[tick, actionIndex]` 입력을 재생해 계산한 점수만 최고 기록에 반영한다. 완료 재요청은 중복 집계하지 않는다.
- 한 판은 활성 플레이 최대 216,000 tick(1시간), 입력 24,000개, tick당 명령 4개, 시작 후 경과 2시간까지 제한한다. 실제 경과 시간보다 빠른 tick 제출도 거절한다. 한도에 도달하면 기록을 저장하고 종료한다.
- 종료 본문만 300KB까지 허용하고 다른 인증 API의 기존 4KB 제한은 유지한다. Redis에서 계정별 조회·시작·검증 횟수를 제한한다.
- 점수 검증은 임의 점수·잘못된 입력·시간 가속 제출을 막는 범위다. 자동 플레이/봇 탐지는 제공하지 않는다.
- 양수 최고 점수를 가진 활성 회원을 점수 내림차순·회원 ID 오름차순으로 정렬한다. TOP 100은 10개씩 번호 페이지로 조회하며, 상단 내 순위는 100위 밖도 표시한다. 닉네임은 최신 회원 정보를 사용한다.

## 검증

- 타입 검사, ESLint, Next 배포 빌드, Java 컴파일.
- 격자·7-bag·홀드·회전·1~4줄 제거와 256개 클라이언트/서버 재생 경로의 점수·보드 일치 확인.
- 독립 MySQL에서 전체 Flyway, 신규 모드, 시작/완료 멱등성, 다른 세션 제출 거절, 100위 제한과 번호 페이지 검증.
- 분리된 브라우저 검증에서 키보드 조작·모달·기록 갱신과 화면 크기별 배치 확인. 임시 테스트 소스는 검증 후 삭제한다.

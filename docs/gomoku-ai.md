# 오목 AI 대전

## 시작과 규칙

- 데스크톱 사이드바와 모바일의 `혼자서(AI 대전)` 버튼에서 같은 난이도 팝업을 연다. 확정 시안대로 제목은 `난이도를 선택해 주세요`, 선택지는 검 아이콘의 노말과 불꽃 아이콘의 하드다. 수치·강도 막대·설명 문구는 표시하지 않는다.
- 난이도 선택 후 `다음`으로 `규칙을 선택해 주세요` 단계로 이동한다. 자유 룰·렌주 룰 카드 중 선택하며 렌주 카드의 이름 아래에 금수·승리 조건을 간단히 표시한다. `이전`으로 돌아가도 선택은 유지한다.
- `게임 시작`은 `/games/gomoku/ai?difficulty=normal|hard&rule=freestyle|renju`로 이동한다. 잘못된 값이나 배열 형태의 난이도·규칙은 404다. 규칙이 없는 기존 링크는 자유 룰로 열린다. 기존 로그인·계정 변경 경계는 유지한다.
- 기존 20×20 판과 마우스 클릭·터치 두 번·키보드 착수를 공유한다. 자유 룰은 양쪽 모두 다섯 개 이상 연결하면 승리한다. 렌주 룰은 흑의 3·3, 4·4, 장목을 금지하고 흑은 정확한 5목, 백은 5목 이상으로 승리한다. 사람의 생각 시간을 제한하지 않는다.
- 렌주의 금수 정의와 가짜 3의 재귀 판정은 [RIF 9.1~9.3](https://gomoku.renju.net/rifrules/)을 따른다. 판 크기와 시작 방식은 기존 서비스처럼 20×20·첫판 사람 선공이며 대회용 오프닝 절차를 추가하지 않는다. 금수 입력은 안내 후 같은 차례에 다시 둘 수 있고, 정확한 5목을 동시에 완성한 수는 승리를 우선한다.
- 첫판은 사람이 흑이다. 재대국은 직전 패자가 흑이며 무승부는 흑백을 바꾼다. 무르기는 판당 한 번, 사람의 직전 착수부터 그 뒤의 AI 착수까지 제거한다. AI 계산 중에도 사용할 수 있다.
- 승패·무승부·기권·재대국은 기존 결과 캐릭터와 팝업을 사용한다. 나가기에는 진행 중인 대국의 종료 확인을 제공한다.
- 데스크톱 대국은 사람 대전과 함께 헤더·푸터를 제외한 실제 본문 높이에 맞춰 판을 배치한다. 좌표와 하단 동작까지 포함해 크기를 계산하며 최대화·창 크기 변경에도 푸터를 표시한다. 작은 터치 화면은 읽기·착수 크기를 유지하는 세로 흐름을 사용한다.
- 방·참가자·대국 DB 행이나 채팅 연결을 만들지 않으며 사람 대전의 API·전적에 결과를 보내지 않는다. 기보는 해당 화면의 메모리에만 있고 새로고침·화면 이동 시 초기화된다.

## 팝업 모드

- 데스크톱에서는 기존 사람 대전과 같은 `useGamePopup`으로 일반 팝업을 연다. 모바일·태블릿의 팝업 표시 조건도 기존과 같다.
- 원본 React 상태와 AI 워커를 유지한 채 대국 UI만 포털로 이동한다. 원본·팝업에 착수 가능한 판을 중복 표시하지 않으며, 계산 중 전환·창 닫기·원래 화면 복귀에도 기보·규칙·무르기 횟수가 유지된다.
- 진행 중 기권·나가기는 팝업 하단 메뉴에서 제공한다. 결과창과 기권 확인창은 실제 대국 창에 표시하며, 나가기 확인은 원래 화면으로 복귀한 뒤 표시한다. 재대국은 같은 팝업과 선택한 난이도·규칙을 유지한다.
- 팝업 차단에는 기존 안내를 제공한다. 원본 탭을 닫거나 대국 화면에서 이동하면 팝업·워커도 정리한다.

## 탐색과 난이도

`ai/contracts.ts`의 내부 강도는 노말 7, 하드 10이다. 이는 사용자 요청에 따른 상대적인 설정이며 대회 등급이나 실측 승률을 뜻하지 않는다. 일부러 악수를 두거나 무작위로 수비를 생략하지 않는다.

| 설정 | 노말 | 하드 |
| --- | --- | --- |
| 일반 탐색 최대 깊이 | 6 ply | 12 ply |
| 기본 후보 폭 | 14 | 24 |
| 연속 4 강제수 탐색 최대 깊이 | 8 ply | 22 ply |
| 한 차례 계산 예산 | 1,100ms | 4,500ms |
| 말단 강제 응수 연장 | 4 ply | 8 ply |

1 ply는 한쪽의 한 번 착수다. 깊이는 상한이며 실제로는 장치 성능·판의 복잡도·시간 예산 안에서 완료한 반복 탐색의 결과를 사용한다. 즉시 승리·필수 수비·증명된 강제승이 있으면 시간을 기다리지 않고 착수한다.

엔진은 양쪽 돌의 중앙 포함 열한 칸 패턴을 캐시하고 착수에 영향받은 네 방향만 증분 갱신한다. 열린 4·끊어진 4·열린 3·4·4·4·3·3·3을 평가하며 알파베타 Negamax, 반복 심화, PVS, 두 해시를 대조하는 전이표, 착수 순서 학습, 말단 강제 응수 탐색을 사용한다. 연속 4 탐색은 상대의 즉시 승리도 확인한 뒤 강제 응수 수순을 증명한다. 하드는 같은 전술 원칙에 더 넓고 깊은 탐색과 긴 강제수 예산을 적용한다.

렌주 탐색은 모든 깊이에서 흑의 금수를 후보에서 제외하고 상대 흑의 금수를 필수 방어·승리 위협으로 평가하지 않는다. 열린 4의 양 끝은 중복 계산하지 않고 같은 방향의 서로 다른 4·4는 구분한다. 가상 확장 수의 금수와 열린 4 양 끝의 장목을 확인해 가짜 3을 제외하며, 가상 착수는 반드시 복원한다. 최종 reducer도 같은 판정기로 응답을 다시 검증한다.

## 실행과 경계

- 계산은 번들된 같은 출처의 전용 Web Worker에서만 수행한다. 외부 AI API·모델 다운로드·서버 CPU 작업이 없으며 UI 스레드에서 동기 탐색하지 않는다.
- CSP는 `worker-src 'self'`만 허용한다. 외부 워커·blob URL·인라인 스크립트 허용 범위를 추가하지 않는다.
- 착수는 판·차례·좌표·중복을 검증한다. 무르기·재대국·언마운트·계정 변경 때 워커를 종료하며 이전 판이나 차례의 응답도 reducer에서 다시 거절한다.
- 워커 로드·메시지·실행 제한 오류에는 재시도를 제공한다. 실패를 감추는 임의 착수나 메인 스레드 대체 탐색은 사용하지 않는다.
- 내부 난이도 수치와 탐색 깊이·점수·노드 수는 UI에 노출하지 않는다. 화면에는 선택한 난이도 이름과 AI 계산 상태만 표시한다.

## 검증

전술과 상태 전이의 임시 검증은 즉시 승리, 연속·끊어진 4 수비, 양 대각선의 판 끝 수비, 열린 4 생성, 연속 4 후 대각선 공격, 열린 3 수비, 장목 승리, 잘못된 판, 증분 패턴 복원, 연속 입력, 무르기 뒤 늦은 응답, 기권·재대국을 포함한다. 렌주 검증은 흑백의 장목 차이, 정확한 5목 우선, 3·3·4·4·같은 방향 4·4, 가짜 3·판 끝, 판 복원, 금수 후 재입력, AI의 금수 제외, 재대국 규칙 유지를 포함한다. 요청에 따라 검증 후 임시 테스트와 검증용 복사본은 삭제한다.

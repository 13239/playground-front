# 페이지 크기와 반응형 공통 기준

루트 `.app-pages`와 페이지 최상위 `.app-page`가 공통 크기 기준을 적용한다. 화면이 넓어지면 본문 폭은 가용 공간을 더 활용하고, 글자·버튼·아이콘·행 높이는 그보다 완만하게 커진다. 모든 값은 상한 이후에 멈추며 배경만 화면 전체를 채운다.

기본 글꼴 16px과 브라우저 배율 100%에서의 기준이다. 실제 모니터 픽셀 수가 아닌 브라우저의 CSS 뷰포트를 사용한다.

| 항목 | FHD 1920px | QHD 2560px | 4K 3840px | 이후 상한 |
| --- | --- | --- | --- | --- |
| 공통 글꼴 / rem | 16px | 약 17.33px | 20px | 기본값의 125% |
| 홈·일반·게임 본문 | 1440px | 1920px | 2250px | 112.5rem |
| 관리자 본문 | 1600px | 약 2133px | 2500px | 125rem |
| 인증 입력 카드 | 520px | 약 563px | 650px | 32.5rem |

`src/app/globals.css`가 수식을 한 곳에서 관리한다. 루트 글꼴은 `clamp(100%, calc(75% + .208333333vw), 125%)`로 FHD 이후부터 증가한다. 본문은 일반 화면 75vw, 관리 화면 약 83.33vw를 활용하되 용도별 최소 기준과 최대 rem 상한을 적용한다. 좁은 화면에서는 부모 너비를 넘지 않는다. 기본 UI 글자는 1rem, 작은 화면은 .875rem이며 인증 입력은 1rem 이상을 유지한다. 기본 글꼴 설정과 브라우저 확대는 존중하며 `zoom`·`transform: scale()`로 페이지를 확대·축소하지 않는다.

일반 페이지는 내용 높이를 사용한다. 짧은 관리자 화면을 화면 아래까지 늘리는 flex 확장을 없애고, 그리드는 현재 페이지의 행 수만큼 늘어난다. 홈의 채팅과 게임판처럼 제한된 표시 영역은 별도 상한을 적용한다. 오목의 대국 셸은 최대 64rem, 게임판은 최대 45rem에서 멈추며 짧은 창에서는 가용 높이에 맞춰 줄어든다. 테트리스의 일반 보드 상한은 42.5rem이며 팝업·전체 화면도 공통 게임판 상한을 따른다.

인증 화면은 입력 카드를 가로·세로 정중앙에 배치한다. 헤더는 위쪽 여백 행에 배치하고 카드 위·아래 행을 같은 비율로 나눠 헤더 높이가 중심을 밀어내지 않게 한다. 긴 가입 폼·작은 가로 화면·화상 키보드처럼 전체 내용이 창에 들어가지 않을 때에는 헤더와 입력을 가리지 않고 문서가 스크롤된다. 장식 삽화 때문에 폼 아래에 비대칭 여백을 추가하지 않는다.

새 페이지는 다음 형태로 시작한다.

```tsx
export default function ExamplePage() {
  return <main className="app-page">내용</main>;
}
```

관리 화면은 `data-page-width="wide"`, 게임은 `data-page-width="game"`, 읽기용 안내는 `data-page-width="reading"`을 지정한다. CSS에서는 공통 gutter·gap·panel padding·title 변수를 재사용하고, 내부 크기는 rem/em으로 공통 증가율을 공유한다. 무제한 vw 글꼴이나 큰 화면에서 다시 확대하는 별도 배율을 추가하지 않는다. 카드 열 수는 실제 남는 폭으로 결정한다.

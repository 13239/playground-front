## 보스 공격

5스테이지마다 보스 한 종류가 등장하는 진행 규칙을 유지한다. 각 보스는 아래 네 패턴을 순환한다.

| 보스 | 패턴 |
| --- | --- |
| 브레이커 | 돌진과 예고 후 후속 부채꼴 사격 → 부채꼴 탄막 → 근접 부채꼴 휘두르기 → 원형 탄막 |
| 센티넬 | 부채꼴 탄막 → 세 갈래 연사 → 양방향 회전 탄막 → 원형 탄막 |
| 디스트로이어 | 중심·주변 연속 포격 → 십자 포격 → 세 갈래 연사 → 원형 탄막 |

- 기본 예고는 0.8초, 돌진은 0.95초, 돌진 후 후속 사격은 별도로 0.75초 예고한다. 포격은 각 원이 나타난 뒤 약 0.9초 후 폭발한다. 시간은 서버 고정 틱 단위로 처리한다.
- 체력이 절반 이하이면 부채꼴 7→9발, 원형 12→16발, 연사 3→4회, 회전 탄막 12→18회(회당 양방향 두 발), 포격 5→7곳으로 강화한다. 연속 공격 뒤 휴식은 1.3→0.95초다.
- 조준은 예고 시 잠근 위치를 사용한다. 공격 종류를 네트워크로 전달해 부채꼴 사선·원형/회전 사선·근접 범위·포격 진행 방향을 구분한다. 돌진 길이와 근접 범위는 공유 상수로 서버·화면을 일치시킨다.
- 서버 틱에서만 연속 공격을 진행한다. 별도 타이머를 만들지 않으며 예약은 최대 18회, 한 틱 발사는 최대 네 회다. 일시정지 시 멈추고 보스 제거·초기화·사격 중단 시 예약 공격을 폐기한다.
- 포격 원은 월드 경계 안으로 제한한다. 일반 사수의 한 발 사격·일반 포격병의 단일 지점 공격은 유지한다.

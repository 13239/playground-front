# 슈팅게임 패턴 공략 전투 — 규칙 버전 5

후속 변경: 현재 맵별 공략 전투·기록 정책은 [규칙 버전 6](shooting-combat-v6.md)을 따른다. 아래 내용은 버전 5의 작업 기록이다.

작업일: 2026-11-05

## 외형·공격·실드

- 헤드폰 공룡의 전투 원화를 수정했다. 양쪽 이어컵과 하나의 헤드밴드, 뒤쪽 등판의 위치를 정리하고, 위쪽 조준 시 총이 머리 옆에 오도록 배치해 총열이 뿔이나 헤드폰처럼 겹치지 않게 했다. 다른 캐릭터 슬롯과 아바타는 유지한다.
- 적 탄환에 어두운 외곽선, 밝은 주황/노랑 몸체, 흰 핵과 긴 잔궤적을 적용했다. 적 공격 예고·탄환은 캐릭터 원화보다 위에서 그린다. 적 보호 오라는 마젠타, 플레이어 실드는 시안으로 구분한다.
- 원거리 조준선은 발사 직전 0.22초에 고정되며 색과 두께가 바뀐다. 저격수는 1.05초 동안 예고하고 속도 1000의 강한 단발을 발사한다. 일반 사수 탄속은 470이다. 벽은 기존과 같이 적 탄환을 막는다.
- E 아이템은 큰 시안 실드, 소모 시간에 따라 줄어드는 호, `SHIELD · 1.9s` HUD와 캐릭터 옆 `1.9s`, 발동·종료 전용 효과음을 제공한다. 양수인 시간은 올림해 소수점 한 자리로 표시한다. 짧은 피격 보호와 부활 보호는 별도 상태이며 E의 큰 실드·카운터를 사용하지 않는다.
- 실드의 실제 보호 시간은 2초, 아이템 재사용 대기는 10초다. 일시정지 시 보호·공격·장치 타이머가 함께 정지한다. 효과는 국소 표시로 구성하고 기존 움직임 줄이기 설정을 유지한다.

## 회피와 전투 구성

대시는 거리 95, 지속 0.1초, 재사용 대기 0.3초다. 대시 자체에는 무적이 없다. 최신 이동 입력을 먼저 전송하고 서버가 방향·벽 충돌·거리를 판정한다. 서버 패치 사이에는 확인된 대시 속도를 짧게 보간한다. 둔화 지역에서도 대시 거리는 유지한다.

일반 피해는 `(24 + 스테이지 × 2.2)`를 기준으로 정예 1.2배, 보스 1.8배, 저격탄 1.65배 등을 적용한 뒤 기존 방어력을 계산한다. 동시 강공격 예고·돌진·예약 연사를 1인 2개, 협동 3개로 제한해 피할 여지를 남긴다. 기존 탄환과 환경 위험은 별도로 진행한다.

| 스테이지 | 임무 | 대응할 요소 |
| --- | --- | --- |
| 1 | 회피의 시작 | 돌진병·사수의 작은 분대 |
| 2 | 조준선을 끊어라 | 저격수·돌진병·방패병 |
| 3 | 장치 제압 | 적과 함께 모든 공략 장치를 파괴해야 클리어 |
| 4 | 지원망 돌파 | 주변 적 피해를 45% 줄이는 지원 드론, 정예·방패병 |
| 5 | 수호자의 시험 | 중간 보스와 지원 분대 |
| 6 | 양면 압박 | 양쪽 출현 위치와 저격·돌진·기동 사수 |
| 7 | 가동을 저지하라 | 36초 안에 장치를 모두 파괴한 뒤 남은 적 처치. 미파괴 시 임무 실패 |
| 8 | 교차 포격 | 맵 고유 기믹과 함께 4.2초마다 두 지점을 1.1초 예고 후 포격 |
| 9 | 총력전 | 양쪽 출현·지원·저격·돌진·방패·포격과 정예 |
| 10 | 최후의 공략 | 최종 보스가 체력 65%·35%에 패턴 순서를 바꾸고 지원 분대 호출 |

6개 맵이 같은 임무 흐름을 공유하며 각 맵의 기존 적·지형·장치 특성을 함께 사용한다. 지원 드론의 보호 반경은 235이고 드론 자신은 보호받지 않는다. 일반 돌진병의 돌진 종료·벽 충돌 뒤에는 약점이 노출된다. 보스도 강공격·연사 종료 뒤 반격 창을 제공한다. 수정 동굴 보스의 돌기둥 유인 공략은 유지한다.

레벨의 자동 성장은 즉시 반영하고 강화 선택은 스테이지 사이에 모아 전투를 중단하지 않는다. UI는 임무·남은 장치·제한시간·보스 단계와 실패 사유를 보여 준다. 조작 설명은 기존 상단 도움말 팝업을 사용한다.

## 기록과 적용

사용자가 선택한 정책을 적용했다. 버전 3·4·5의 획득 별과 맵 해금은 함께 보존한다. 고난도 랭킹·내 최고 기록·맵별 최고 시간은 버전 5만 집계한다. 이전 기록을 삭제하거나 별을 낮추지 않는다. 신규 기록 제출은 버전 5만 허용한다.

프론트엔드, 전투 서버(`game/playground`), Spring MVC 백엔드를 같은 변경으로 적용해야 한다. 진행 중인 이전 규칙 전투를 마친 뒤 전환해야 하며, 새 스키마와 규칙을 반영하려면 전투 서버와 백엔드 재시작이 필요하다. 작업 중 사용자 실행 프로세스를 종료하지 않았다.

## 검증

- 게임 서버 TypeScript 검사와 프론트 TypeScript·슈팅 기능 ESLint 통과.
- 임시 검증 페이지를 제거한 최종 Next.js 프로덕션 빌드 통과. 기존 `features/auth/server/login-audit.ts`의 동적 파일 경로 추적 경고 6개는 남아 있으며 이번 슈팅 변경과 별개다.
- 임시 격리 검증 통과: 6개 맵 × 1인/협동의 12개 전체 상태 전환, 10개 구간 기록과 5·10 보스, 모든 맵의 7스테이지 제한시간 실패, 12개 보스 출현 지형의 충돌 여유, 장치 미파괴 클리어 차단.
- 대시 거리·0.3초 재사용·무적 없음, E 보호·소모·일시정지, 소수점 시간 표기, Colyseus 상태 직렬화, 지원 드론 보호 해제, 동시 공격 제한, 저격 추적→조준 고정→탄속, 보스 단계별 일회성 소환, 교차 포격 검증 통과.
- Spring Java 컴파일과 임시 서비스 테스트 2개 통과: 과거 별·해금 유지 및 현재 최고 시간 분리, 구버전의 고난도 랭킹 제외. 실제 DB를 변경하지 않는 저장소 대역으로 검증했다.
- 실제 Phaser·공유 시뮬레이션·입력·HUD를 연결한 임시 화면을 앱 내 브라우저에서 확인했다. 시안색 실드와 `1.9s`, 저격선·탄환·공룡 외형, 제한시간 목표를 확인했고 경고·오류 로그는 없었다.
- CSS 뷰포트 1920×1080, 1280×720, 768×1024, 390×844, 844×390, 2560×1440, 3840×2160, 4096×2880에서 가로 넘침 없이 표시했다. 낮은 창은 세로 스크롤을 허용했다. 검증용 맵·스테이지 선택 버튼이 추가한 높이는 실제 화면과 구분했다. 진행 제목 글자는 FHD 16.8px, QHD 18.9px, 4K 23.1px로 변했다.
- 임시 테스트 소스와 인증·기록 API를 사용하지 않는 검증 페이지는 확인 후 삭제했다. 기존 테스트는 유지했다.

전체 상태 전환 검증은 적·장치를 강제로 제거해 진행 조건을 검사한 것으로, 자연 플레이의 난이도 검증을 대신하지 않는다. 실제 사용자 2명의 장시간 협동, 실제 DB 기록 저장, 효과음 청취, Chrome·Edge·Firefox·Safari 개별 실행, 모바일 멀티터치와 실제 5K는 미검증이다. 앱 내 브라우저가 요청한 5120px을 4096px로 제한했다. 사람의 체감 난이도와 별 기준 시간은 실제 플레이 후 추가 조정할 수 있다.

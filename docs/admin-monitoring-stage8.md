# 관리자 8단계 화면

`/admin`은 조회 권한이 있는 첫 메뉴로 진입하며 대시보드 권한이 있으면 `/admin/dashboard` 화면을 기본으로 표시한다. `/admin/service-status`는 별도 권한 메뉴다. 각 메뉴·데이터 요청은 `DASHBOARD_READ`, `SERVICE_STATUS_READ`를 독립 적용한다.

운영 대시보드는 현재 접속·오늘 신규회원 두 카드, 오늘/7일/30일 접속 현황 한 그래프로 구성한다. 현재 접속은 최근 60초에 인증 확인된 로그인 회원을 중복 제거한다. 오늘은 시간별, 7일/30일은 일별 최대다. KST 기준으로 표시하며 초기 집계·확인 불가·지연·실제 0을 구분한다. 값이 없는 그래프 구간은 선과 채우기를 끊고 미래 시간은 표시하지 않는다. SVG 원형 지점은 키보드 초점과 값 설명을 제공한다.

서비스 상태는 로그인·게임·채팅 세 행에 상태·확인 항목·마지막 확인 시각을 표시한다. 정상/지연/장애/확인 불가를 텍스트·아이콘·색으로 구분한다. 고정 세 항목이므로 페이징과 표시 개수 선택은 없다. 모바일에서는 행을 카드 형태로 재배치한다. 주기 점검은 실제 업무를 생성하지 않는 운영 연결 확인이다.

두 화면은 보이는 문서에서만 30초마다 데이터를 갱신한다. 아이콘 새로고침은 기존 시계방향 회전 버튼을 공유한다. 그림의 `예시 데이터` 표시는 실제 화면에 넣지 않으며 임의의 기본 통계를 표시하지 않는다. 메뉴가 늘어난 모바일 가로 탐색에서는 선택한 메뉴가 보이도록 이동하고 본문 위치는 바꾸지 않는다. 고해상도는 기존 본문 최대 폭과 SVG 선명도를 유지한다.

BFF는 허용된 두 GET 경로와 `period` 값만 전달한다. 세션 식별자·중복/미등록 쿼리·누락/음수/잘못된 응답·KST 구간·요청/응답 기간 불일치를 검사하고 표시 필드만 복사한다. 숨겨진 수집·진단·서비스 제어 경로를 공개하지 않는다.

메인 서버 V19와 채팅 내부 상태 API를 함께 반영한다. 초기 이전 구간은 빈 그래프로 시작한다. [서버 집계 기준·설정](../../../back/playground/docs/admin-monitoring-stage8.md), [구현 검증·화면](../../../artifacts/admin-development-stage8/verification.md)을 참조한다.
